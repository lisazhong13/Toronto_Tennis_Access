# Toronto Tennis Access

## Overview

This repository contains the data, code, and paper for an analysis of City of Toronto tennis facilities. The paper combines the City's tennis facility records with neighbourhood boundaries and 2021 Census population data to describe how courts differ by operation type (Public or Club), lighting, and winter-play designation, and how many reported courts each neighbourhood has per 10,000 residents.

The main findings are that nearly all Club records have lights (63 of 66) compared with just over half of Public records (62 of 107), that Public records hold most winter-play designations, and that 57 of Toronto's 158 neighbourhoods contain no City tennis court.

The paper is available at paper/paper.pdf.

## Data sources

All data are downloaded from Open Data Toronto using the opendatatoronto R package:

-   [Tennis Courts – Facilities](https://open.toronto.ca/dataset/tennis-courts-facilities/), published by Parks, Forestry and Recreation.
-   [Neighbourhoods](https://open.toronto.ca/dataset/neighbourhoods/), the boundaries of Toronto's 158 neighbourhoods.
-   [Neighbourhood Profiles](https://open.toronto.ca/dataset/neighbourhood-profiles/), used for 2021 Census neighbourhood population.

## File structure

The repo is structured as:

-   data/raw_data contains the raw data as downloaded from Open Data Toronto.
-   data/analysis_data contains the cleaned dataset used in the paper.
-   data/simulated_data contains the simulated dataset.
-   other/llm contains the complete LLM chat history (usage.txt).
-   other/sketches contains sketches of the planned dataset and graphs.
-   other/literature contains relevant literature.
-   paper contains the Quarto document (paper.qmd), the bibliography (references.bib), and the rendered PDF.
-   scripts contains the R scripts used to simulate, test, download, and clean the data.

    -   scripts/01-test_simulated_data.R tests the simulated data.

    -   scripts/04-test_analysis_data.R tests the cleaned data.

This repository contains the data, code, and paper for an analysis of City of Toronto tennis facilities. The paper combines the City's tennis facility records with neighbourhood boundaries and 2021 Census population data to describe how courts differ by operation type (Public or Club), lighting, and winter-play designation, and how reported court supply varies across Toronto's neighbourhoods.
